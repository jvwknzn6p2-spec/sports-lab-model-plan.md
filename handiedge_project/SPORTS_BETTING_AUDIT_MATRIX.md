   an artifact of this extraction.

   document, including in the Deployment Checklist chapter that would be the natural home for it.
4. **Category 10 (bankroll/risk controls)** only computes a raw, uncapped Kelly fraction with no
   exposure limits, correlation handling, or stop conditions — flagged per this skill's hard rules
   as needing fractional caps and stop-loss logic before any real staking use.

   the Week-3 Definition-of-Done in Chapter 1 explicitly requiring a Brier-score improvement proof.
6. No chapter's code has been executed in this workspace. Per this skill's hard rules, **no
   component in this document may be described as "complete," "production-ready," or "tested"** —
   the document's own Handoff section (p.83–84) states this same conclusion independently.
