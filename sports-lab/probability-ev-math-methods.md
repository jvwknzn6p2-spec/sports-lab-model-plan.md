# 確率・EV計算のための数学手法 5選 — 専門家レベル解説

_高確率の予想と正確な期待値(EV)判定を支える、本システム(AI Sports Lab / HandiEdge)の数学的基盤。各手法について「何であるか」「なぜ効くか」「実際の計算」「本パイプラインでの使われ方」を解説する。_

---

## 1. オッズの逆算とヴィグ除去 — インプライド確率(implied probability)

### 何であるか
ブックメーカーのオッズを「市場が織り込んでいる確率」に変換する技術。EV計算の出発点であり、これを誤ると以降の全計算が歪む。

### 基本式
デシメルオッズ `d` に対して:

```
インプライド確率 p = 1 / d
```

例: オッズ 1.91 → p = 1/1.91 ≈ 52.4%

ただし両チームのインプライド確率を合計すると **100% を超える**(例: 52.4% + 52.4% = 104.8%)。この超過分がブックメーカーの手数料 **ヴィグ(vig / overround)** であり、これを除去しないと市場の「真の見立て」は得られない。

### ヴィグ除去の主な方法
- **比例配分法(multiplicative)**: 各確率を合計で割る。`p_fair = p_i / Σp`。最も簡便だが、大穴側の確率を過大評価しがち。
- **べき乗法(power method)**: `Σ (1/d_i)^k = 1` となる指数 `k` を数値的に解く。favorite–longshot バイアスをある程度補正する。
- **Shin 法**: インサイダー(情報優位の賭け手)の存在を仮定した理論モデル。大穴バイアスの補正力が最も高いとされ、シャープな市場の逆算に向く。

### なぜ専門家レベルで必須か
- モデルの勝率とフェア確率の差 = **エッジ** がEVの源泉。ヴィグ込みの確率と比較すると、実在しないエッジを「発見」してしまう。
- **クロージングライン価値(CLV)**: 試合直前の最終ラインは最も効率的な市場価格とされる。自分のベット価格が最終ラインより良かったかを追跡することは、長期的な優位性の最良の先行指標になる。

### 本システムでの位置づけ
Odds API から取得したマーケットラインをフェア確率へ逆算し、モンテカルロ由来のモデル確率と比較してエッジを算出する(§4.3 EV計算の前段)。未入力のハンデ/トータルラインを市場コンセンサスで補完する `fetch-slate` も同じ変換に依存する。

## 2. ベイズ統計 — 事前分布・縮小推定・平均への回帰

### 何であるか
「観測データ」と「事前知識(リーグ平均など)」を数学的に融合する枠組み。少サンプルの暴れを抑え、**平均への回帰(regression to the mean)** を定量的に扱う。

### 基本式(ベイズの定理)
```
P(仮説 | データ) = P(データ | 仮説) × P(仮説) / P(データ)
```

実務で最も使うのは **ベータ二項モデルによる縮小推定(shrinkage)**:

```
推定率 = (実測成功数 + α) / (試行数 + α + β)
```

ここで `α, β` はリーグ平均を中心とするベータ事前分布のパラメータ。直感的には:

```
縮小後の指標 = w × 選手の実測値 + (1 − w) × リーグ平均
w = n / (n + k)   (n: サンプル数、k: 指標ごとの安定化定数)
```

打席数 `n` が小さいほど `w` が小さくなり、推定はリーグ平均側に引き寄せられる。

### なぜ効くか
- 開幕20打席で打率 .450 の打者を「.450 の打者」と扱うのは統計的過信。ベイズ縮小は「本当の実力はおそらく .270 台で、まだ証拠が薄い」と正しく表現する。
- 事後分布は点推定だけでなく**不確実性の幅**も与える。これが確信度ランク(S/A/B/C)の数学的根拠になる。
- 新情報(直近フォーム、負傷情報)が入るたびに事後分布を**逐次更新**でき、日次パイプラインと相性が良い。

### 本システムでの位置づけ
`lib/sports-data` の「サンプルサイズの誠実さ」原則そのもの — 投球回/打席数でリーグ平均へ回帰させ、各特徴量に 0–1 の信頼度ウェイトを付与している。FIP や wOBA のような欠陥の少ない指標を選ぶことも、事前分布の質を上げる工夫の一部である。

## 3. 得点分布のモデリング — ポアソン分布・負の二項分布・スケラム分布

### 何であるか
「期待得点 4.6 点」という1つの数字を、**起こりうる全スコアの確率分布**に展開する数学。勝敗・ランライン・トータルの確率はすべてこの分布から導かれる。

### 基本式
得点のような「一定時間内に起こる事象の回数」はまず **ポアソン分布** でモデル化する:

```
P(得点 = k) = λ^k × e^(−λ) / k!    (λ: 期待得点)
```

ただし野球の得点は連鎖的(ビッグイニング)に発生し、分散が平均を上回る **過分散(overdispersion)** を示す。そこで実務では分散を別パラメータで制御できる **負の二項分布** に切り替えるのが定石:

```
ポアソン:   分散 = 平均
負の二項:  分散 = 平均 + 平均²/r   (r: 分散を制御する形状パラメータ)
```

両チームの得点差(マージン)は、2つのポアソン変数の差が従う **スケラム分布(Skellam distribution)** で解析的に扱える:

```
P(ホーム − アウェイ = m) = e^(−(λ1+λ2)) × (λ1/λ2)^(m/2) × I_m(2√(λ1λ2))
```

(`I_m` は修正ベッセル関数)

### なぜ効くか
- ランライン(−1.5)のカバー確率は「マージン ≥ 2 の確率」であり、分布なしには計算できない。
- トータル(O/U)は両チーム得点の合計分布の裾の面積。ラインが 8.5 か 9.0 かで裾の切り方が変わるため、分布の形状(特に過分散の程度)が精度を直接左右する。
- 分布の仮定を明示すれば、バックテストで「モデルの分散は現実と合っているか」を検証できる(実測の裾が太ければ過信のサイン)。

### 本システムでの位置づけ
ベースラインモデル(§4.1)が出す両チームの期待得点 λ を、この分布ファミリーがスコア分布へ展開する。モンテカルロ(次節)は本質的にこの分布からのサンプリングであり、遠い裾の縮小補正(`farTailShrink`)は「モデルの裾が現実より太い/細い」ことへのウォークフォワード検証に基づく較正である。

## 4. モンテカルロシミュレーションと収束理論 — 大数の法則・中心極限定理

### 何であるか
解析的に解きにくい複合確率(先発降板後のブルペン継投、天候、延長戦など条件が絡み合う事象)を、**試合を数千〜数万回仮想的に再生して数える**ことで求める手法。

### 数学的裏付け
- **大数の法則**: 試行回数 N → ∞ でシミュレーション上の勝率は真の勝率に収束する。
- **中心極限定理**: 推定確率の標準誤差は

```
SE = √( p(1−p) / N )
```

例: 真の勝率 p ≈ 55%、N = 10,000 回なら SE ≈ 0.5%。つまり1万回のシミュレーションで勝率は ±1%(2σ)の精度が得られる。**精度は √N でしか改善しない**ため、10倍の精度には100倍の試行が必要 — 必要な N はこの式から逆算して決める。

### 専門家レベルの要点
- **相関の保存**: 勝敗・ランライン・トータルを別々に計算せず、**同一のシミュレーション試行**から同時に集計する。「打高の展開で勝つ」「投手戦で勝つ」の相関構造が自然に保たれ、3つの出力の整合性が保証される。
- **入力の不確実性も回す**: λ 自体を事後分布(§2)からサンプリングしてから試合を回すと、「パラメータの不確実性」まで含んだ誠実な確率になる(そうしないと過信した確率が出る)。
- **分散低減**: 共通乱数(比較時)、層別サンプリングなどで同じ N からより高い精度を引き出せる。

### 本システムでの位置づけ
§4.2 の中核。ベースラインの期待得点を受け取り、1万回規模の試合再生から「勝ちシミュ率 → マネーライン」「マージン ≥ 1.5 の率 → ランライン」「合計得点の分布 → O/U」を同時に出力する。

## 5. EV計算・較正・ケリー基準 — エッジを利益に変える数学

### 何であるか
モデル確率と市場価格の差(エッジ)を金額的価値に換算し、**いくら賭けるべきか**まで含めて最適化する、最終段の数学。

### EVの基本式
デシメルオッズ `d`、モデル勝率 `p`、賭け金1単位に対して:

```
EV = p × (d − 1) − (1 − p) × 1
```

例: p = 60%、d = 1.91 → EV = 0.60×0.91 − 0.40 = **+0.146**(+14.6%のエッジ)。EV > 0 のベットだけを長期反復すれば、大数の法則により利益が期待できる — **ただし p が正しければ**。

### 較正(calibration)— EVの前提を検証する数学
「60%と言った試合は本当に約60%勝っているか」を測る。主要スコア:

```
Brier スコア = (1/N) Σ (予測確率 − 実結果)²      (小さいほど良い)
対数損失     = −(1/N) Σ [y·log(p) + (1−y)·log(1−p)]  (過信を厳しく罰する)
```

信頼度曲線(reliability diagram)で予測確率帯ごとの実勝率を可視化し、系統的な過信/過小評価が見つかれば **Platt スケーリングや等調回帰(isotonic regression)** で事後補正する。**較正されていない確率から計算したEVは無意味** — これが本手法群の中で最も見落とされやすい急所である。

### ケリー基準(Kelly criterion)— 賭け金サイズの最適化
資金の長期成長率(対数資産)を最大化する賭け金比率:

```
f* = (d−1)·p − (1−p)      p: 勝率, d: デシメルオッズ, f*: 資金に対する賭け率
     ─────────────
         d − 1
```

例: p = 60%、d = 1.91 → f* = (0.91×0.6 − 0.4)/0.91 ≈ **16.0%**。

ただしフルケリーは p の推定誤差に極端に脆く、過大賭けは**期待成長率を負にすら**する。実務は **分数ケリー(1/4〜1/2ケリー)** が標準:

- 1/4ケリーは成長率の約44%を確保しつつ、資産の分散(ドローダウン)を約1/16に抑える。
- 推定エッジには必ず誤差があるため、分数化は「推定過信への保険」として数学的に正当化される。

### 本システムでの位置づけ
§4.3 のEV計算(市場フェア確率 vs モデル確率)、§4.4 バックテストの較正検証(`data/calibration.json` の `tailShrink` / `farTailShrink`、較正不良時の S→A 確信度キャップ)、そして日次レポートのステーク提示(クォーターケリー)がこの手法群の実装である。

## 5手法の関係 — 1本のパイプラインとして

```
① オッズ逆算      市場のフェア確率を得る(比較対象のベースライン)
        │
② ベイズ縮小      少サンプルに歪まない入力(選手・チーム能力の推定)
        │
③ 得点分布        期待得点 → スコアの確率分布(Poisson/負の二項/Skellam)
        │
④ モンテカルロ    分布から数万試合を再生 → 勝率・ランライン・O/U確率
        │
⑤ EV・較正・ケリー  エッジ算出 → 確率の検証 → 最適賭け金
```

どれか1つが欠けても成立しない: ②が甘ければ③の λ が歪み、④の確率が歪み、⑤のEVは虚構になる。逆に⑤の較正がフィードバックとして②〜④の改善点を教える。**「高確率で当てる」とは1試合を当てることではなく、出力する確率そのものを現実と一致させ(較正)、市場との差があるときだけ適切なサイズで賭ける(EV+ケリー)ことである。**
